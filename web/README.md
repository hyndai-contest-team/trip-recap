# 왔다감 휴대폰 공유 페이지

차량 앱이 QR 로 보여 주는 URL(`https://<호스트>/#<hash>`)을 휴대폰에서 열면 이 페이지가 `#` 뒤의 여행 데이터를 풀어 화면에 그린다.
서버는 데이터를 받지 않는다(`#` 뒤는 브라우저가 전송하지 않는다). 사진은 휴대폰 브라우저 안에서만 읽는다.
npm 패키지, CDN, 빌드 도구를 쓰지 않는다. ES module 과 순수 JS 다.

## 구조

| 파일 | 내용 |
|---|---|
| `index.html`, `css/style.css` | 화면. CSP 로 외부 요청을 막는다(`connect-src 'none'`, script·style 은 같은 출처만, 인라인 style 속성 금지) |
| `js/main.js` | DOM 코드. hash 해석 → 머리·경로 그림·들른 곳(타임라인)·공유할 이미지, 아래 고정 바, 사진 읽기, 공유 |
| `js/codec.js` | 공유 바이트 형식 v1 해석(`decodeHash`)과 시험용 `encode`. 차량 앱 `ShareCodec.kt` 와 같은 형식 |
| `js/projection.js` | Web Mercator 투영 + 상자 맞춤(`mercator`, `fit`). 차량 앱 `RouteProjection.kt` 와 같은 계산 |
| `js/exif.js` | JPEG EXIF `DateTimeOriginal`(없으면 `DateTime`) 읽기, 한국 시간으로 해석해 epoch 분으로 변환, `File.lastModified` 대체 |
| `js/photos.js` | 사진 배치(`assignPhotos`), 타임라인 줄과 "이동 중" 줄 위치(`timelineRows`), 요약 문장(`photoCounts`, `photoSummary`), 썸네일 읽기 이름(`thumbLabel`) |
| `js/bar.js` | 아래 고정 바의 버튼 문구·안내·동작 고르기(`barState`) |
| `js/format.js` | 거리·시간·날짜(올해면 연도 생략)·시각 표기(Asia/Seoul 기준), "n박 n+1일", 숫자·단위 나누기, 카카오맵·네이버지도 링크 |
| `js/cards.js` | 번호 점 규칙(`stopMarks`)과 겹친 점 묶기(`groupMarkers`), 경로 그림 높이·설명, 공유 이미지 4종 배치(`layoutCard`, `layoutStopPages`)와 canvas 그리기(`drawCard`, `drawStopPage`, `drawRoute`) |
| `test/*.test.js` | 단위 테스트 (`node:test`), 105개 |
| `test/fixtures/*.json` | Kotlin 테스트와 함께 쓰는 fixture. 수정하면 양쪽 테스트를 모두 다시 돌린다 |

화면 구성: 머리(브랜드, 날짜·인원, 제목, 숫자 3칸) → 경로 그림 → 들른 곳(요약 줄, 타임라인) → 공유할 이미지 → 바닥글. 화면 맨 아래에 고정 바(안내 한 줄 + 버튼 하나)가 있다. 이 화면 대신 안내 화면을 보여 주는 경우는 세 가지다: hash 가 없으면 QR 찍는 3단계 안내, 데이터가 중간에 끊겼으면 다시 찍기 안내, 형식 버전이 다르면 새로 고침 버튼.

## 테스트

저장소 루트에서:

```sh
node --test web/test/
```

`main.js` 는 단위 테스트 대상이 아니다. 문법 확인과 화면 확인은 아래처럼 한다.

```sh
node --check web/js/main.js
cd web && python3 -m http.server 8000
# 브라우저에서 (hash 는 test/fixtures/share-v1.json 의 "hash" 값)
# http://localhost:8000/#AYr7oA6bC7QSAwzqsr3tj6ztlbTrs4ACAJKTLv6tnQGCAVAM6rK97Y-s7ZW067OABo8FuAbrAbAJBuyImeyGjAO-5i2mlJsB1CzYmQKPBbgG
```

ES module 은 `file://` 로 열면 불러오지 못한다. 반드시 HTTP 서버로 연다.

## 배포

정적 호스팅(Netlify, Cloudflare Pages 등)에 올릴 것은 `index.html`, `css/`, `js/` 세 가지다. `test/` 와 `README.md` 는 올리지 않아도 된다.
게시 폴더를 `web/` 로 지정해도 동작한다(이 경우 `test/` 도 함께 공개된다).

- HTTPS 로 제공해야 한다. `navigator.share` 는 HTTPS 에서만 동작한다.
- 호스팅 서비스의 분석 스크립트 삽입 기능은 끈다. 켜면 CSP 에 막히거나 외부 요청이 생긴다.
- 차량 앱 `local.properties` 의 `share.baseUrl` 을 배포 주소(끝에 `/`)로 맞추고 다시 빌드한다. QR 주소는 `SharePayload.url(baseUrl)` 이 만든다.

## 동작 규칙

- 번호: 방문지(VISIT)만 번호를 센다. 숙박은 "숙", 잠깐 정차는 번호 없는 회색 점. 숫자 칸 "들른 곳 n곳"과 번호 최댓값이 같다(차량 앱 `Trip.visits` 와 같은 기준).
- 경로 그림에서 겹치는 번호 점(중심 거리 < 지름×1.1)은 연속한 번호끼리 pill 하나로 묶어 "2–3"처럼 쓴다. 숙박이 섞이면 "2·숙". 묶은 pill 끼리 겹치면 다시 합친다. 화면과 공유 이미지가 같은 규칙을 쓴다.
- 화면 경로 그림 높이는 경로 범위의 세로/가로 비율로 정하고 160~300 으로 자른다. 경로도 정차도 없으면 그림을 숨긴다. 경로 없이 정차만 있으면 정차를 점선으로 잇고 "실제 경로 대신 들른 곳을 순서대로 이었어요."를 보여 준다.
- 걸린 시간: 숙박 정차가 n번이면 "n박 n+1일", 없으면 "10시간 35분".
- 사진 배치: 촬영 시각이 방문지 도착~출발(양 끝 포함) 안이면 그 방문지, 아니면 "이동 중". 잠깐 정차 구간의 사진도 "이동 중"으로 본다. "이동 중" 줄은 그 사진 시각보다 앞서 도착한 마지막 정차 다음에 놓는다(첫 정차 전이면 맨 위).
- EXIF 시각에는 시간대가 없다. 한국 시간(UTC+9)으로 해석한다. 해외에서 찍은 사진은 시각이 어긋난다.
- EXIF 를 못 읽는 파일(PNG, 메신저로 받은 사진 등)은 파일 저장 시각으로 배치하고 썸네일에 "시각 추정"을 표시한다. 브라우저가 열지 못하는 형식(Android Chrome 의 HEIC 등)은 "열 수 없음"으로 표시하고 이미지에 쓰지 않는다.
- 방문지 썸네일을 누르면 그 방문지의 대표 사진(들른 곳별 이미지에 들어가는 사진)이 바뀐다. 처음에는 그 곳의 첫 사진이 대표다.
- 사진 배경 이미지의 배경은 "공유할 이미지" 구역의 배경 사진 줄에서 고른다. 고르지 않으면 첫 대표 사진.
- 카드 종류 기본값: 사진이 있으면 "사진 배경", 없으면 "스토리". 사용자가 종류를 고른 뒤에는 바꾸지 않는다.
- 아래 고정 바(`barState`): 사진 0장 → "갤러리에서 사진 고르기"(파일 선택). 사진이 있고 "공유할 이미지" 구역이 화면 밖 → "공유 이미지 만들기"(구역으로 스크롤하고 "사진 배경" 선택). 구역이 화면 아래 1/4 위로 올라오면 → "이미지 공유하기"(여러 장이면 "이미지 3장 공유하기"). 동작을 줄이는 설정(`prefers-reduced-motion`)이면 스크롤을 바로 옮긴다.
- 공유 화면(`navigator.share`)을 열 수 없는 브라우저는 "n번째 이미지 저장" 링크를 보여 준다.
- 저장 파일: 사진이 없는 카드는 PNG, 사진이 들어간 카드는 JPEG(품질 0.92).
- 공유 이미지는 4종이다: 사진 배경·스토리 1080×1920, 정사각형 1080×1080, 들른 곳별 1080×1350(한 장에 3곳까지, 넘으면 여러 장). 좌표는 `js/cards.js` 의 `CARD_SPECS`·`layoutStopPages` 에 있다. 스토리·사진 배경은 위 250px, 아래 280px 을 비운다(인스타그램 스토리 화면 요소 영역). 스토리·사진 배경의 제목은 76 → 60 → 60 두 줄, 숫자는 80 → 72 → 64 로 줄인다. 정사각형은 제목 68 → 56 → 56 두 줄, 숫자 72 → 64 다.

## 실기기 확인 항목

iOS Safari 와 Android Chrome 에서 각각 확인한다. 데스크톱 Chrome 개발자 도구의 기기 emulation 모드(390×844)로는 확인했다.

- [ ] QR 을 찍어 연 주소에서 제목, 날짜·인원, 숫자 3칸, 경로 그림, 타임라인이 보인다
- [ ] hash 없이 열면 "차에서 QR 코드를 찍어 주세요"와 3단계 안내가 보인다
- [ ] 아래 고정 바가 홈 표시줄(iPhone)·제스처 막대(Android)에 가리지 않는다(`env(safe-area-inset-bottom)`)
- [ ] 아래 바 "갤러리에서 사진 고르기"와 "사진 더 고르기"가 사진 선택기를 연다(실제 파일 선택기)
- [ ] 카카오맵, 네이버지도 링크가 방문지 위치를 연다(앱 설치/미설치 두 경우)
- [ ] 기본 카메라로 찍은 JPEG 가 EXIF 시각으로 배치된다("시각 추정" 표시가 없다)
- [ ] iOS: HEIC 로 저장된 사진을 고르면 Safari 가 JPEG 로 바꿔 넘기는지, 그때 EXIF 시각이 남는지("시각 추정" 표시 여부로 확인)
- [ ] Android: 사진 선택기(Photo Picker)로 고른 사진에 EXIF 시각이 남는지, HEIC 사진이 "열 수 없음"으로 나오는지
- [ ] 카카오톡으로 받은 사진, 스크린샷은 "시각 추정"으로 표시된다
- [ ] 사진 30장 이상을 한 번에 골라도 페이지가 다시 로드되지 않는다(메모리)
- [ ] 세로로 찍은 사진이 썸네일과 이미지에서 올바른 방향으로 나온다
- [ ] 스크롤해서 "공유할 이미지" 구역이 보이면 바 버튼이 "이미지 공유하기"로 바뀐다
- [ ] "이미지 공유하기"를 누르면 공유 화면이 열리고, 사진 앱에 저장되거나 카카오톡·인스타그램으로 보낼 수 있다. 보낸 뒤 "보냈어요. 다른 이미지도 만들 수 있어요."가 나온다
- [ ] 들른 곳별 이미지가 여러 장일 때 공유 화면에 모든 장이 들어간다
- [ ] 저장된 이미지 크기가 1080×1920(사진 배경, 스토리), 1080×1080, 1080×1350 이다
- [ ] 이미지의 한글 글꼴이 깨지지 않고 숫자와 단위의 기준선이 맞는다(기기 기본 글꼴 사용)
- [ ] 시스템 글자 크기 200% 에서 숫자·지도 링크가 한 글자씩 끊기지 않는다
- [ ] VoiceOver·TalkBack 이 썸네일을 "경포해변 사진, 11시 10분. 누르면 대표 사진으로 써요"처럼 읽는다
- [ ] 브라우저 개발자 도구 Network 탭에 이 호스트의 정적 파일 외 요청이 없다
