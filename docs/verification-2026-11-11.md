## 에뮬레이터 관찰
- 앱이 터치에 반응하지 않는 상태가 한 번 재현됐다(시연 여행 넣기 → 검색 열고 닫기 → 지우기 → 시나리오 재생 → 도착 카드 닫기 뒤). 그때 `dumpsys input` 에는 시스템 앱 `ai.umos.drivingview/.DrivingViewActivity` 의 입력 차단 창(ActivityRecordInputSink, 화면 전체)이 우리 앱 창보다 위에 있었고, 앱의 화면 요소 구조(uiautomator)에는 터치를 가로채는 요소가 없었다. 화면 갱신과 debug 명령은 정상이었다. 앱을 다시 시작하면 풀렸다. 같은 순서에서 검색 단계만 뺀 경우와 각 단계를 따로 한 경우에는 재현되지 않았다. 우리 앱이 원인인지는 가리지 못했다.
