### 색 사용 규칙
- 강조색은 앰버 #F5A623 하나다. 앰버는 아래에만 쓴다.
  - 주 행동 버튼(`PrimaryButton`). 화면당 1개. 예외: 상세에서 방문지 카드를 펼쳤을 때 카드 안 "여기로 안내"와 아래 고정 줄 "휴대폰으로 보내기"가 둘 다 앰버다.
  - 핵심 숫자: 주행 중 숫자 칸, 도착 카드 숫자 칸. 상세·코스 숫자 칸 값은 흰색이다.
  - 경로 선과 번호 점(`RouteCanvas.kt`, `NumberDot`).
  - "1년 전 이맘때" 칩과 그 카드 테두리, "새 여행" 칩(`AmberChip`).
  - 켜진 스위치 트랙(`WatSwitch`).
  - 그 밖에 앰버를 쓰는 곳: 상세 화면에서 펼친 방문지 카드의 선택 테두리 3px, 동의 화면 앱 이름, 목록 카드의 "기록 중" 점(지름 12. 진행 중 여행 표시).
- 구역 제목·머리말·켜진 선택 칩에는 앰버를 쓰지 않는다. 켜진 선택 칩은 ChipOn #E0E1E6.
- 지우기만 예외 색을 쓴다: 지우기 글자 버튼 #FF7A5C, 지우기 확인 버튼 바탕 #FF4C28 + 글자 #131417.
- 비 표시만 파랑 계열(Rain)이다.
- 앱 아이콘은 이 규칙의 예외다: 경로 선과 점 2개가 하늘색 #4FC3F7, 배경이 #101418 이다(`res/drawable/ic_launcher_foreground.xml`, `res/values/colors.xml` `bg`).
- Text50 은 bg(#1D1E21) 위에서만 쓴다. 카드(#313236) 위에서는 대비 4.45:1 로 4.5:1 에 못 미친다.

## 컴포넌트 (`ui/Components.kt`)
### 버튼
| 종류 | composable | 모양 | 높이 |
|---|---|---|---|
| 주 행동 | `PrimaryButton` | 앰버 바탕, 글자 #131417 32/700, pill | 112(아래 고정 줄, 동의, 도착 카드, 빈 목록 "기록 켜기"), 88(대화상자), 80(방문지 카드 안 "여기로 안내") |
| 보조 | `SecondaryButton` | 바탕 흰색 8%, 글자 흰색 28/500, pill | 같은 줄의 주 행동과 같은 높이(112·88·80). 혼자 쓰는 곳(검색 "조건 지우기", 시연 도구)은 80 |
| 글자 | `TextButton` | 바탕 없음, 28/500 Text72, 좌우 24 | 80 (방문지 카드 "이름 바꾸기", "공유에서 빼기") |
| 지우기 글자 | `DangerTextButton` | 바탕 없음, 28/500 #FF7A5C, 좌우 24 | 80 ("이 여행 지우기", 방문지 "지우기", "모든 여행 지우기"). 누르면 대화상자로 한 번 더 묻는다 |
| 지우기 확인 | `DangerFillButton` | 바탕 #FF4C28, 글자 #131417 32/700, pill | 88. 대화상자 안에서만 |
| 원형 아이콘 | `CircleIconButton` | 80×80 원, 바탕 흰색 8%, 선 아이콘(`Icons.kt` `AppIcon`) | 80 ("뒤로", "설정"). 제목 옆 연필은 바탕 없이 Text72 |
- pill 버튼 좌우 여백: 높이 112 → 48, 88 → 40, 80 → 32. 글자는 한 줄로만 쓰고 넘치면 말줄임.
- 버튼 순서: 왼쪽 보조 / 오른쪽 주 행동. 대화상자 왼쪽 버튼은 "닫기".
- 응답을 기다리는 동안 버튼 글자를 바꾸고(`busyText`) 누를 수 없게 한다. 예: "메모 말하기"는 음성을 받는 최대 8초 동안 "듣고 있어요".

### 선택 칩, 스위치
- 선택 칩(`SelectChip`): 높이 80, pill, 28/500, 좌우 32. 켜짐 = 바탕 #E0E1E6 + 글자 #131417 + 체크 아이콘 28. 꺼짐 = 바탕 흰색 8% + 흰 글자 + 빈 원 아이콘 28(Text50). 아이콘과 글자 사이 10. 켜짐·꺼짐의 폭이 같다. 목록 TopBar 의 [검색]은 아이콘 없이 바탕색만 바뀐다(`showMark = false`).
- 스위치(`WatSwitch`): 트랙 104×56 pill, 원 지름 44. 켜짐 = 트랙 앰버 + 원 #131417 오른쪽. 꺼짐 = 트랙 #44464E + 원 #A4A8AE 왼쪽.
- 스위치 행(`SwitchRow`): 최소 높이 112, 좌우 40 위아래 16. 제목 28/500, 설명 26 Text72. 행 전체가 눌리고, 누르는 동안 트랙이 95% 로 줄어든다. 설정은 카드 안에 구분선(`ListDivider`)으로 나눠 넣고, 코스 화면은 행 하나가 카드(반지름 24)다.

### 숫자 칸 (`StatCell`, `StatRow`)
- 값 48/800 흰색 아래 라벨 24/500 Text72, 사이 4. 단위는 값에 붙여 쓴다("413km"). 칸 사이 64, 폭이 모자라면 다음 줄로 넘긴다(줄 간격 16).
- 도착 카드는 값이 앰버. 주행 중은 값 96/800 앰버 + 라벨 32/500, 가운데 정렬, 칸 폭 360·간격 120(좁은 창은 간격부터 24 까지 줄인다).
- 좁은 창 상세는 값 40/800.
- 라벨: 달린 거리 / 여행 시간 / 방문 / 함께 탄 사람(2명 이상일 때만). 주행 중은 달린 거리 / 방문지. 코스 "지난번"은 전체 시간 / "(가장 오래 머문 곳)에서" / 잠깐 들른 곳.

### 번호 점
- 번호는 방문지만 센다(차량 화면·휴대폰 페이지·공유 이미지 공통). 숙박은 "숙", 잠깐 정차는 번호 없이 회색 작은 점.
- 목록형 화면(`NumberDot`): 지름 48 앰버 + 숫자 26/700 #131417. 코스 화면에서 안내 중인 구간의 점은 지름 60 흰 바탕 + 32/700. 잠깐 정차(`IdleDot`)는 지름 16 #A4A8AE 를 48 칸 가운데에 그려 이름 시작선을 맞춘다.
- 경로 그림(`RouteCanvas.kt`): 선 굵기 8 앰버, 번호 점 반지름 24(선택된 방문지 30, 흰 바탕) + 그림 바탕색 테두리 3. 점 중심 간격 90 이상으로 떼어 놓고, 옮긴 점은 원래 위치까지 흰색 50% 선(2)으로 잇는다. 방문지가 한 지역에 몰려 확대하면 번호 점과 겹치지 않는 모서리(겹치는 점 수가 같으면 경로 선이 덜 지나가는 곳, `domain/RouteFraming.kt` `miniMapCorner`)에 전체 경로 미니맵 220×160(바탕 #1D1E21, 반지름 16, 선 3, 확대 영역 사각형 2 Text72)을 둔다. 목록 카드 미니 그림(240×112)은 선 4, 점 반지름 6, 번호·미니맵 없음.

### 칩
- 작은 칩(`TagChip`): 높이 48, pill, 24/500, 좌우 20. 비(`RainChip`) = 글자 #6FB8FF + 바탕 #0082FF 18%. 공유 제외(`MutedChip`) = 글자 Text72 + 바탕 흰색 8%. "1년 전 이맘때"·"새 여행"(`AmberChip`) = 바탕 앰버 + 글자 #131417.

### 카드
- 목록 카드(`listCard`): Surface, 반지름 28, 안쪽 좌우 40 위아래 28, 높이 168 이상. "1년 전 이맘때" 카드는 앰버 테두리 3px.

### 눌림 효과
- 버튼·선택 칩·원형 아이콘 버튼은 누르는 동안 95% 로 줄이고(100ms) 바탕색을 바꾼다(`pressScale`, `PressScale.BUTTON`). ripple 은 쓰지 않는다.
- 폭이 큰 카드(목록 카드, 방문지 카드, 시연 도구 펼침 행)는 98% 로 줄이고 바탕색을 바꾼다(`PressScale.CARD`). **가이드의 95% 와 다르게 적용한 곳이다.** 이유: 폭 1570 카드를 95% 로 줄이면 좌우 끝이 39px 씩 안쪽으로 움직여 카드 전체가 흔들려 보인다. 98% 면 16px 이다.

## 레이아웃·상호작용
- 한 손 조작, 한 번 터치. 터치 대상 높이는 80 이상(작은 칩 48 은 누를 수 없는 표시다).
- 좌우 여백 56(좁은 창 32), 화면 위 여백 40. 동의 화면은 좌우 72(좁은 창 32).
- 주행 중: 동영상·애니메이션·자동 스크롤 금지. 주행 제한 중에는 주행 중 화면만 보이고 터치를 받지 않는다(`AppRoot.kt`). 정차하면 보던 화면으로 돌아간다.
- 사용자 입력 후 0.25초 안에 응답한다. 응답이 늦어지면 응답 중인 상태를 화면에 표시한다(위 `busyText`). 결과는 알림으로 알린다.
- portrait(841 폭)와 landscape(1682 폭) 두 레이아웃을 모두 설계한다. 코드는 창 폭 1200dp 미만을 portrait 로 본다(`Components.kt` `isPortrait`). portrait 에서는 목록 카드의 미니 경로 그림, 상세·코스의 경로 그림을 숨기고, 상세 숫자 칸 값을 40 으로, 상세 아래 고정 줄을 화면 폭으로 두고 보조 버튼을 "다시 가기"로 줄인다. 공유 화면은 QR 을 640 에서 520 으로 줄이고 정보를 QR 아래에 놓는다(2열 행은 라벨을 값 위에 쌓는다). 검색 칩 5개는 넘치면 다음 줄로 넘긴다.
- 모서리: 버튼은 pill(반지름 = 높이/2). 카드 반지름은 위 "카드".
- 모션은 가이드가 정한 스크롤 끝 바운스와 눌림 축소만 쓴다. 화면 전환·알림 애니메이션은 넣지 않는다. 주행 중 화면에는 모션이 없다.

## 문구 규칙
- 모두 해요체다. 예: "여행을 저장했어요", "지우면 되돌릴 수 없어요."
- 같은 행동은 한 이름으로 쓴다: **지우기 / 뒤로 / 닫기 / 바꾸기 / 보내기**. "삭제·취소·수정·요청"을 쓰지 않는다. 예: "이름 바꾸기", "휴대폰으로 보내기", 대화상자 왼쪽 "닫기".
- 버튼은 누르면 일어나는 일을 쓴다. 상태("켜짐")를 버튼 글자로 쓰지 않는다.
- 사용자 화면에 API·좌표·데이터·서버·바이트·파일 이름 같은 개발자 용어를 쓰지 않는다. 예외: 설정의 시연 도구 안 글자와 debug 빌드 전용 안내.
- "(으)로", "을(를)" 표기를 쓰지 않고 조사를 맞춘다(`domain/Josa.kt`). 예: "강릉중앙시장을 지울까요?", "안목해변 카페를 지울까요?", "41km를 달렸어요". 영문 뒤 조사는 붙여 쓴다("QR로").
- 숫자 표기(`domain/TripSummary.kt` `Texts`):
  - 숙박이 있는 여행의 시간은 "2박 3일"(숙박 정차 수 = 박). 없으면 "10시간 35분".
  - 날짜는 올해면 연도를 뺀다: "11월 7일 (토)". 다른 해는 "2025년 11월 10일 (월)".
  - 거리는 10km 이상 정수, 미만은 소수 1자리("8.5km"). 주행 중 화면은 정수 km 로 버림하고 1km 부터 보인다.
  - 머문 시간 "1시간 20분", "45분". 다음 날 출발은 "20:00 – 다음 날 9:30".
  - 음성(TTS)은 고유어 수를 쓴다: "세 곳 다녀온 여행을 저장했어요."
